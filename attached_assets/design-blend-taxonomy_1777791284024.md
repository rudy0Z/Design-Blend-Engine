# Design Blend — Deep Taxonomy
### UI/UX Design + Graphic Design — Full Style Breakdown

**Philosophy:** Every style node must be visually distinct enough that a designer 
sees the reference image and has an immediate gut reaction. If two styles look 
similar to a layperson, they need to be merged or one needs a better image.

## QUIZ FLOW LOGIC

### Field Selection

User selects which fields they want to be profiled on:

```
PRIMARY (pick at least 1):
☑ UI / UX Design        ← pre-selected for target audience
☑ Graphic Design        ← pre-selected for target audience
☐ Brand Identity
☐ Typography
☐ Motion Design
☐ Illustration
☐ 3D Design
☐ Photography

"We'll ask about the fields you select. 
 More fields = more accurate profile. 
 Minimum time: ~8 min. Maximum: ~25 min."
```

### Category Selection Within Fields

After field selection, user picks which categories interest them most:

```
UI/UX DESIGN — Which aspects do you design?
☑ Visual Design Language
☑ Layout & Composition  
☑ Color Philosophy
☐ Motion & Interaction (skip if you don't do interaction)
☑ Typography in UI
☑ Product Type Aesthetic
☐ UX Patterns (skip if you're pure visual)
```

This prevents a pure visual designer from rating UX patterns they've never thought about. Only rate what you actually care about.

### Styles Per Session

Based on fields + categories selected:

| Selection | Approx Styles | Time |
|---|---|---|
| UI/UX only, all categories | 85 styles | ~11 min |
| Graphic Design only, all | 95 styles | ~13 min |
| Both fields, all categories | 180 styles | ~24 min |
| Both fields, selected categories | 60–100 styles | ~8–13 min |

Target: **under 15 minutes** for a focused selection. The skip mechanic (swipe left fast) helps — familiar styles get fast ratings, unfamiliar ones get considered.

## IMAGE CURATION NOTES

For each style, one canonical reference image. Priority sources:

**UI Styles:** Real screenshots from the referenced products. Request permission or use press kit images.

**Graphic Design Styles:** 
- Public domain for historical styles (Bauhaus, Constructivist, Art Nouveau)
- Behance with permission for contemporary
- Commission original examples for ambiguous styles

**One rule:** The image must make a designer say "oh yes, I know exactly what that is" within 2 seconds. If it requires explanation, find a better image.
